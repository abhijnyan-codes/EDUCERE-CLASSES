# EDUCERE CLASSES Website

A modern premium coaching institute website built using React, Vite, Tailwind CSS, and Framer Motion.

## Features
- Responsive premium UI
- Courses section
- Student testimonials
- Contact & location section
- Smooth animations
- Modern SaaS-inspired design

## Tech Stack
- React
- Vite
- Tailwind CSS v4
- Framer Motion

## Run Locally

```bash
npm install
npm run dev

Build

npm run build
